Weather location

Resolved from a US zip code — Zippopotam.us turns it into coordinates, then api.weather.gov turns those into a forecast grid and the nearest observation station — the same two free, keyless steps this install's own default location was resolved through by hand. A zip's centre point isn't your exact address (it can land a mile or two off), which is fine for a forecast grid cell but worth knowing.

Colour picker

The contrast gate is never optional — every swatch below is the exact same math the panel itself uses (src/palette.js), so a colour that fails its floor is lightened until it passes, not shipped broken. Preview happens instantly against the real pane on the right; nothing is written to disk until you press Save.
